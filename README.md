# Akshat — Portfolio

Personal portfolio of **Akshat**, DevOps Engineer.

Built with a modern, optimized, mobile-first stack.

## Tech Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **react-icons**

## Features

- Fully responsive, mobile-first layout
- Accessible, semantic HTML with SEO metadata & Open Graph tags
- Scroll-spy navigation with animated reveals (IntersectionObserver)
- Centralized, type-safe content in [`src/data/portfolio.ts`](src/data/portfolio.ts)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description               |
| --------------- | ------------------------- |
| `npm run dev`   | Start the dev server      |
| `npm run build` | Production build          |
| `npm run start` | Serve the production build |
| `npm run lint`  | Run ESLint                |

## Editing Content

All content (experience, projects, skills, education, certifications) lives in
[`src/data/portfolio.ts`](src/data/portfolio.ts). Update that single file to
change what the site shows — no component edits required.

## Deployment

Deploy easily on [Vercel](https://vercel.com/) — import the repo and it builds
automatically.
